# ☘️ Emerald Eats

> A responsive catering website developed for Emerald Eats, an Irish street food and event catering business based in London.

This repository showcases my implementation of the Emerald Eats website, developed as freelance work for a real client. Working from the client's designs and requirements, I built a responsive marketing website that showcases their catering services, menus and event offerings.

Following the initial launch, I continued to maintain the website by implementing additional features and updates based on client feedback. The live website has since undergone further design changes, so it may differ from the version contained in this repository.
